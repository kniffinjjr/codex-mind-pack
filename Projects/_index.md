# Projects index

Registry of **active projects** living under this pack.  
This file starts empty of real projects on purpose. Agents and humans add one line when a folder is created.

| Slug | Path | Status | One-line purpose |
|------|------|--------|------------------|
| *(none yet)* | — | — | Copy `Projects/_template` → `Projects/<slug>` and register here |

## Convention

- **Slug:** lowercase, hyphenated, no spaces (`pdm-eco-scorecard`).
- **Status:** `active` | `paused` | `done` | `archived`.
- **Purpose:** one sentence; detail stays in that project’s `Overview.md`.

When a project is done, mark status `done` or move the folder to `Projects/_archived/` (create if needed) and leave a pointer row here.
