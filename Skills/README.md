# Skills (Codex Mind Pack)

Portable skill **routing** for this work pack. Full operational skill bodies often live in local agent skill directories or in the private AI-Mind-Vault.

| File | Purpose |
|------|--------|
| `Agent-Skill-Map.md` | Persona → skill map + design / implement clusters + design rules |
| `Relocate-Consolidate.md` | Discover, classify, merge, and tombstone existing `SKILLS.md` / `skills.md` files |

**Related**

- Personalities (paste packs): `../personalities/`
- Core architecture: `../AGENTS.md`, `../core/`
- Private full catalog: AI-Mind-Vault `Skills/` (approval-gated)
- Local path overrides: `../PATHS.md` (optional `SKILLS_RUNTIME`)

**Policy**

- Do not keep a long-lived root `SKILLS.md` in this pack. Use the map + personalities.
- Relocate/consolidate any existing catalogs per `Relocate-Consolidate.md`.
- Do not put domain residue or personal-only skills here.
