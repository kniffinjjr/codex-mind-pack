# Specialist Personalities (Codex / GPT ready)

These are optional, paste-ready ≤4000-character instruction packs for specialized agents. They are adapted from the private AI-Mind-Vault Grok Agent Personalities so the same research and domain capability is available under a pure Codex / GPT surface.

**All packs still obey the core rules in `AGENTS.md`.** They apply Harness · Loop · Graph; they do not replace it.

## How to use

1. Copy the desired block into a Codex / GPT custom-instruction field, or into a project-level AGENTS.md / system prompt.
2. Keep the core `AGENTS.md` (or its equivalent) higher priority so architecture, residue, Writer ≠ Checker, and cost discipline remain binding.
3. Activate via the listed triggers or by name.
